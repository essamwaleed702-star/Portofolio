I build the systems that run quietly in the background — and make sure they keep running.

I'm a backend developer focused on turning product requirements into dependable server-side infrastructure. My work centers on designing REST APIs, modeling relational databases, and implementing authentication and authorization flows that hold up under real-world load.

I favor clean architecture over clever shortcuts — clear boundaries between layers, predictable data flow, and code that's easy for the next engineer to reason about. Whether it's a CRUD endpoint or a multi-service platform, I care about the same things: correctness, security, and the ability to scale without a rewrite.
